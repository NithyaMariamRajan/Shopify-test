# Shopify Custom Theme Assignment

## Overview
This project is a custom Shopify theme implementation based on the provided Figma design. It includes a custom banner and product grid with interactive features.

---

## Features

- Custom Banner section (Figma-based layout)
- Product Grid section
- Hover zoom effect on product images
- Product quick view popup
- Color and size selection (UI)
- Responsive design

---

## Tech Stack

- Shopify Liquid
- HTML
- CSS
- JavaScript

---

## Sections Implemented

### 1. Custom Banner
- Hero layout with background image
- "Choose Gift" button
- "Shop Now" CTA with hover effects

### 2. Custom Grid
- Dynamic product listing from collection
- Product cards with image, title, and price
- Add to cart button
- Quick view popup with options

---

## How to Use

1. Add the sections in Shopify Theme Customizer:
   - Custom Banner
   - Custom Grid

2. Select a collection in Custom Grid settings

3. Configure banner image and links in Custom Banner settings
